01

Foundation

The base — login, companies, roles, shared staff
Depends on: nothing

Goal: Set up the core structure — one CEO, 20 companies, 3 entities, and staff that can be shared across companies. Everything above stands on this.

Modules

A1Auth & Login
A2Users & Roles (CEO / Manager / Staff)
A3Companies (20 portfolio)
A4Entities (CA / PK / Remote)
A5Shared Staff Pool
A6Permissions
M1 Done when: a user can log in, the 20 companies exist, roles work, and one staff member can be assigned to multiple companies.
02

ClickUp Task System

The core product — boards, tasks, chat, mentions
Depends on: 01

Goal: The heart of the app. The CEO assigns tasks to managers; everyone collaborates inside the task with threads, mentions, files and voice notes — replacing scattered WhatsApp groups.

Modules

B1Workspaces / Spaces
B2Boards / Lists
B3Groups
B4Tasks
B5Columns & Custom Fields
B6Status (To-do / WIP / Done)
B7Comments / Task Thread
B8Channel Chat
B9@Mentions
B10Attachments + Voice Notes
B11Activity / Audit Log
B12Attention Needed Radar
M2 Done when: the CEO assigns a task to a manager, the manager replies in-thread with a file, an @mention lands in the Attention radar, and the task moves to Done.
03

Leave & Attendance (HR)

Punch in/out, late tracking, leave approvals
Depends on: 01

Goal: Track who's present, late or on leave. These records are the raw input that Payroll (04) uses for deductions — so this comes first.

Modules

C1Employee Directory & Contracts
C2Attendance / Punch In-Out
C3Late Detection
C4Leave Types
C5Leave Requests & Approvals
C6Leave Balances
C7Partial / Hourly Passes
M3 Done when: staff can punch in/out, a leave request flows to a manager for approval, and the balance updates automatically.
04

Payroll

CA bi-weekly, PK monthly, contractor, cash
Depends on: 03

Goal: Run payroll per entity with the right cycle, applying leave and late deductions automatically, then route the run for CEO approval.

Modules

D1Pay Cycles (Bi-weekly / Monthly / Milestone)
D2Salary Structure
D3Leave & Late Deductions
D4Overtime
D5Payroll Run → CEO Approval
D6Payslips / Invoices
D7Reimbursements & Claims
M4 Done when: a pay run generates payslips with leave/late deductions applied, and the CEO approves the cycle.
05

CEO Dashboard + AI

Capstone — only displays data, stores nothing
Depends on: 01–04

Goal: One control tower that reads and combines everything below — workforce, per-company tasks, approvals, payroll — plus an AI copilot to summarize it all.

Modules

E1Executive Metric Tiles
E2Company Portfolio View
E3Managers & Teams View
E4Attention Needed (mentions + approvals)
E5Live Pulse Ticker
E6AI Copilot (summarizes all layers)
M5 Done when: the dashboard shows real tiles, per-company task streams, a working Attention radar, and the AI copilot answers questions from live data.
Upward ↑
Data flows up

Task, leave and payroll data is created below and surfaces, aggregated, on the CEO dashboard (05).

Downward ↓
Control flows down

The CEO assigns tasks/approvals from the top, which reach managers and staff below.
