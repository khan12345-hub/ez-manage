# ClickUp — what we saw in the team's real account (read-only, 2026-11-06)

Looked at with the owner's permission, read-only (no item created, edited or deleted;
inbox items were not opened so nothing was marked read). Business names are left out.
Use together with `clickup-feature-inventory.md` (397-item public checklist).

## Navigation
- **Left icon rail:** Home, Planner, **AI** (newer workspace), Teams, Dashboards, Forms, Goals, Timesheets, More, Invite.
- **Home menu:** New, Inbox, Replies, Assigned Comments, Posts, **Skills**, **Artifacts**, **Meetings**, My Tasks, More.
- **AI Chats** section with chat history; **Agents** section: *Brain* + *New Super Agent*.
- **Spaces** (with private 🔒 ones), *All Tasks*, *Shared with me*; folders → lists with open-task counts.
- **Channels** (many, mostly private) and **Direct Messages** with each teammate.
- **Top bar:** workspace switcher, Search (Ctrl K) + **AI Chats**, running **time-tracker** widget, Talk to Text, record clip.

## Task view (modal, with prev/next)
- **Header:** breadcrumb, **"+1"** (task in multiple lists), Connect, Share, ⋯, favourite, layout toggle.
- **Top of task:** task **type** selector ("Task"), task ID, subtask count.
- **Fields:**
  - Status with a one-click ✓ complete
  - Assignees
  - **Dates** start → due with duration ("3d")
  - Priority
  - **Time estimate**
  - **Sprint points**
  - **Track time** (running timer + total)
  - Tags
- **Body sections:**
  - Description
  - **Add fields** (custom fields)
  - Subtasks with a progress bar
  - **Relate items / dependencies**
  - **Checklists**
  - **Assigned comments** (resolved/open)
  - Attachments
- **Right panel:**
  - **Comments and activity history merged** in one timeline (status/date changes)
  - **Threaded replies**
  - Composer tabs **Comment / Post / Email**
  - Tools: attach, @mention, assign comment, emoji, video clip, AI, voice.

## List view
- View bar per list, as used: Channel, Board, Team, Calendar, Google Sheets (embed), List.
- **"+ View" types:**
  - **Popular:** List, Gantt, Calendar, Doc, Board, Form, Dashboard, Gallery.
  - **More:** Table, Whiteboard, Timeline, Activity, Workload, Mind Map, Team, Map, Collection.
  - **Embeds:** website, Google Sheets/Docs/Calendar/Maps, YouTube, Figma.
  - **Options:** Private view, Pin view.
- **Toolbar:** Group by (Status…), Subtasks collapsed/expanded, Columns, Filter, **Closed** toggle, Assignee, Search, Customize, Add Task (split button).
- **Groups:** custom statuses (e.g. "Needs review"), per-column **Calculate** (aggregates), **New status** inline, "Explore fields & columns", a **Sprints** column (assign or move between sprints).

## Inbox & collaboration pages
- **Inbox:** tabs Primary / Other / **Later** / **Cleared**; Filter; settings; Clear all. Grouped Today / Yesterday / Last 7 days. Events: overdue, reactions, added to channel, mentions with attachments.
- **Replies:** Unread / Read; "Read old replies".
- **Assigned Comments:** **Assigned to me / Delegated by me**; Filter, Resolved toggle, date range, Search.
- **Posts:** composer with channel, type (Announcement…), title, mention a task, video clip, new task or whiteboard, **Schedule for later**. A feed of followed channels with Channel/Author/Type filters.
- **My Tasks home (cards):** Recents, Agenda, My Work (To Do / Done / **Delegated** → Today, Overdue, Next, Unscheduled), Assigned to me. "Manage cards".

## Other sections
- **Planner:**
  - calendar sync (Google/Outlook)
  - join meetings
  - **AI Notetaker** that transcribes and creates action items
  - **time-blocking** of tasks
- **Teams:** Teams Hub with team feed, members, online status, browse teams and people.
- **Dashboards:** list with location, owner and sharing; templates such as Simple, **Client Portal** and Project Management.
- **Forms:** templates for Feedback, Project Intake, Order, Job Application and IT Requests.
- **Goals:** goals with % progress and targets (used per client), folders, archived.
- **Timesheets:** "Create Entry".

## AI (newer workspace)
- **Skills:** "Skills Miner" turns repeated work into skills. Also team skills and create-from-scratch, plus templates: *Update Like Me* (standups in your voice), *Write Like Me*, *Scope Like Me*, *Triage Tasks Like Me*.
- **Artifacts:** AI-generated, shareable outputs:
  - data visualisations
  - slide decks
  - interactive prototypes and tools
  - documents and reports
  - landing pages
- **Meetings:** AI prompt ("turn action items into follow-up tasks"), upcoming meetings, send AI Notetaker, meeting notes with tags.
- **Brain** chat agent (model picker, Skills in the composer) and **Super Agents**.
